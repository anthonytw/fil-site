fil

Reprendre le fil: to pick up the thread where you left off.

A remote shell for development over SSH that keeps your place.

  • Sessions that survive reconnects, roaming and sleep, with your terminal's own scrollback.
  • Reattach after a crash, or take a session over from another machine.
  • Port forwards that stay open across reconnects.
  • Direct QUIC, or a plain SSH pipe when UDP is blocked.
  • Shows what you type before the host echoes it, on slow links (new in 0.2.0).
0.2.0 is out 
brew install anthonytw/tap/fil        # macOS, Linux
cargo install --locked fil-shell       # from source

The .deb and .rpm packages and the signed archives are on the 0.2.0 release; the install guide covers them, Arch and Nix, and how to check a download. Then fil HOST works like ssh HOST, and offers to put fil on the host the first time. The code, the design and the changes are on GitHub.
