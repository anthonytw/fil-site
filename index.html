fil

Reprendre le fil: to pick up the thread where you left off.

A remote shell for development over SSH that keeps your place.

Install fil 0.2.0 Quick start
~ — zsh
# attach to (or create) session "main"
$ fil devbox
# after Enter, ~. detaches
# come back, from here or elsewhere
$ fil devbox
# session "build", port 5173 forwarded
$ fil devbox build -L 5173
# the sessions; what each one holds
$ fil ls devbox
$ fil ports devbox

What it does

  • Reconnects transparently

    After a dropped link, a sleeping laptop or a change of network, with your terminal's own native scrollback.

  • Keeps sessions

    Reattach after a local crash, or take a session over from another machine.

  • Holds port forwards open

    -L, -R and -D survive reconnects, and fil ports shows what each session holds.

  • QUIC, or a plain SSH pipe

    Connects directly over QUIC, or over SSH when UDP is blocked, and moves between the two by itself.

  • No root, no service

    One program on the host, run as you. It respects the host admin's sshd forwarding settings.

  • Predictive echonew in 0.2.0

    Shows what you type before the host echoes it, as mosh does, when the round trip is long enough for that to help.

It has no panes: your terminal already does that. fil is run over ssh, so your keys, ~/.ssh/config and jump hosts apply. How it compares with ssh, Eternal Terminal and mosh.

Install

On macOS and Linux, x86_64 and aarch64. fil goes on the host too: fil install HOST puts it there over your ssh login, or the first fil HOST offers to.

The .deb and .rpm packages and the signed archives are on the 0.2.0 release. The install guide covers Fedora, Arch and Nix too, and how to check a download.

install
# macOS, Linux
$ brew install anthonytw/tap/fil
# Debian, Ubuntu (from the release)
$ sudo apt install ./fil_0.2.0_amd64.deb
# from source; the command is fil
$ cargo install --locked fil-shell

New in 0.2.0: predictive echo

Over a slow link every key takes a round trip before it appears. fil can draw the character at once, as a guess, and replace it with what the host really sends. It is on by default above about 30 ms of round trip, underlined while the link is slow, held back at password prompts (the guide lists four rare cases where it is not) and in full-screen programs, and predict = "off" turns it off. How it works.

A known limit in 0.2.0, to be fixed in 0.2.1. Once something interrupts the run of guesses (Enter, Tab, Ctrl-W, a Backspace while keys are in flight, the end of the line, or fish's and zsh's autosuggestions), prediction stays off until your typing slows below about one key per round trip. That is slower than many people type, so on a long round trip you will often see no guesses. It never shows anything wrong: you see your keys when the host echoes them, as over ssh.
